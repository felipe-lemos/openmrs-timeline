A Gutenberg block plugin for displaying a timeline of OpenMRS events, milestones, or releases in a visually engaging way.

---

## Description

**OpenMRS Timeline** provides a custom Gutenberg block to display a timeline of events, milestones, or releases for OpenMRS. The block is fully compatible with the WordPress block editor and can be inserted into any post or page. It is styled to match the OpenMRS design system and is easy to use and configure.

### Features

- 🟢 Custom "Timeline" block for the WordPress editor
- 🗓️ Visual timeline of events, milestones, or releases
- 🎨 Color scheme support (teal, purple, orange, etc.)
- 📱 Responsive and accessible design
- ⚙️ Easy to use and configure

---

## Installation

1. Upload the plugin files to the `/wp-content/plugins/openmrs-timeline` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. In the block editor, search for **"OpenMRS Timeline"** and insert the block into your page or post.

---

## Frequently Asked Questions

### How do I add a timeline?

After activating the plugin, open the WordPress block editor, search for **"OpenMRS Timeline"**, and insert the block. You can then add and edit timeline items directly in the editor.

### Can I customize the colors?

Yes! The block supports multiple color schemes (teal, purple, orange, etc.) to match your site or OpenMRS branding.
